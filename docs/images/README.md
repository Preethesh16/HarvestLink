# Capture provenance

These are real Playwright captures of the locally running HarvestLink application, taken during implementation on 21 October 2026. All participants, inventories and histories are synthetic. The separate mandi report contains genuine, dated government data with its coverage and reporting date visible. No personal accounts, secrets or actual payments appear.

- `farmer-dashboard.png`: procedural Three.js scene and seeded farmer inventory.
- `restaurant-forecast.png`: actual local Chronos-2 inference with the synthetic restaurant history.
- `negotiation.png`: proposals from the most recent test or recording; the narrated recording uses credentialed OpenAI proposals with server validation.
- `order-settled.png`: completed simulated transaction.
- `mobile.png`: narrow viewport layout.

The browser suite regenerates the workflow captures. `frontend/e2e/inspect.mjs` captures the farmer overview. The separate recording script captures the complete demonstration.

Entrance update: `landing.png`, `sign-in.png`, `farmer-assistant.png` and `kannada-workspace.png` show the animated entrance, scoped demo login and actual native-language farmer interface. The 3D bee is adapted from the user-owned Inception project.
